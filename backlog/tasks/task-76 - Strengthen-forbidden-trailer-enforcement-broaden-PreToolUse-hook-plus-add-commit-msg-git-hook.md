## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The current `commit-msg-guard` PreToolUse hook in `.claude/settings.json` (and its sibling `gh pr create` guard) only fires when:
1. The Bash command string starts with `^git commit\b` (or `^gh pr create\b`), AND
2. The forbidden text (`Co-Authored-By`, `Generated with Claude Code`, `## Test plan`) appears literally in the command string.

A real-world report from another project showed a Ralph autonomous commit slipped a `Co-Authored-By` trailer past the hook. The Claude Code PreToolUse hook has fundamental visibility limits — it sees only the Bash command string, not file contents, git config side-effects, or commit-msg assembly. Known bypass paths:

1. **`-F file`**: `git commit -F /tmp/msg` — trailer lives in the file, hook never reads it.
2. **Piped/compound commands**: `printf \"...Co-Authored-By...\" | git commit -F -`, `echo ... && git commit -m \"...\"`. Prefix anchor `^git commit\b` doesn't match → hook short-circuits via `exit 0` and never checks content.
3. **Indirection**: `cd dir && git commit ...`, `bash -c 'git commit ...'`, `git -c trailer.coauthored.command=... commit ...`.
4. **Git auto-trailer config**: `git config trailer.coauthored.command` (global or project) auto-appends — trailer text is not in the command.
5. **`.git/hooks/commit-msg` or `commit.template`** injecting the trailer at commit-message build time.

A single fix can't catch all paths. Use a two-layer defense.

## Layer 1 — broaden the PreToolUse hook

In `.claude/settings.json`, update both `commit-msg-guard` (matches `git commit`) and the parallel `gh pr create` guard:

- **Drop the prefix anchor** in the trigger check. Currently: `grep -qE '^git commit\\b' || exit 0`. Change to `grep -qE '\\bgit commit\\b' || exit 0` — matches `git commit` anywhere in the command, not just at the start.
- Apply the same change to the `gh pr create` guard: `grep -qE '\\bgh pr create\\b' || exit 0`.
- Keep the forbidden-content check unchanged (it already scans the full command string).

This catches cases 2 and 3 above — any compound command that includes the literal trailer text in the same Bash invocation.

Mirror the change in `skills/ralph-init/templates/settings.json` so newly-bootstrapped projects get the fix.

## Layer 2 — add a `commit-msg` git hook

Create `templates/commit-msg` in `skills/ralph-init/templates/` with the following bash logic:

```bash
#\!/usr/bin/env bash
# Reject commits whose final assembled message contains forbidden text.
# Triggered by git for ALL commit paths: -m, -F file, --amend, template,
# auto-trailer config, .git/hooks/prepare-commit-msg injections.

set -euo pipefail
msg_file=\"$1\"

# Allow merge commits (auto-generated by git).
[ -e .git/MERGE_MSG ] && exit 0

# Skip squash/fixup messages (those are intermediate).
case \"$(cat \"$msg_file\")\" in
  squash\!*|fixup\!*) exit 0 ;;
esac

if grep -qiE 'Co-Authored-By|Generated with Claude Code' \"$msg_file\" || \\
   grep -qE '##[[:space:]]*Test [Pp]lan' \"$msg_file\"; then
  echo \"BLOCKED: commit message contains forbidden trailer/heading.\" >&2
  echo \"Remove Co-Authored-By, Generated-with, and Test plan sections.\" >&2
  exit 1
fi

exit 0
```

Distribution mechanic:

- `skills/ralph-init/SKILL.md` Step 3.3 currently writes `templates/post-commit` to `.git/hooks/post-commit`. Add a parallel write of `templates/commit-msg` to `.git/hooks/commit-msg`. Make executable. Same overwrite-warning logic if the file already exists.
- Install in this project too: copy `templates/commit-msg` to `.git/hooks/commit-msg` after merge (manual step or part of TASK acceptance).

Git hands the hook the fully-assembled commit message file regardless of how it was built (`-m`, `-F file`, auto-trailer, template, prepare-commit-msg injections). This closes cases 1, 4, and 5.

- `gh pr create --title 'foo' --body 'has Generated with Claude Code text'` — block

Layer 2 (commit-msg git hook, runs on every commit):
- Set `git config trailer.coauthored.command 'echo Co-Authored-By: X'` then `git commit -m 'foo'` — git auto-appends trailer; hook reads assembled message and blocks. Unset config after test.
- Write a multiline message to /tmp/msg containing `Co-Authored-By:` then `git commit -F /tmp/msg` — block.
- `git commit -m 'task-99: clean'` — allow.
- Merge commit (`git merge feature-branch`) — allow (no false positive).

## Out of scope

- Auto-correcting commits (stripping trailers automatically) — keep as deny-only.
- Blocking `git commit -F` entirely — too aggressive; valid use case is editor-driven workflows.
- Distributing `commit-msg` outside Ralph-init projects.
